Say Hello Chat to start Codex Voice, and Bye Chat to end it.

Hello Chat is a native Mac app that listens for both phrases with a local speech model, then opens or ends Voice in the Codex desktop app.

Setup

Check Codex Voice works on its own first, then let Hello Chat open and end it.

  1. 1

    Start Voice in Codex yourself

    Sign in to the Codex desktop app and check Voice works. Hello Chat can only open Voice that Codex already offers you.

  2. 2

    Download Hello Chat

    Download the signed, notarised app, unzip it and move HelloChat.app to Applications. No developer tools are needed.

  3. 3

    Allow Microphone and Accessibility

    Microphone is for local listening. Accessibility lets Hello Chat use Codex’s Voice shortcut and End Voice control. If macOS does not ask, add Hello Chat in System Settings → Privacy & Security → Accessibility. If H Chat says new shortcuts need a Codex restart, restart Codex once.

  4. 4

    Choose your microphone

    Choose Microphone on Home. Codex Voice keeps its own input setting.

  5. 5

    Turn on Listen for wake phrase

    Hello Chat prepares the local model, then shows the live microphone level. Listening status is also in the menu bar. Transcripts are saved on your Mac by default; turn off Save transcripts in Settings → Transcript Archive to stop saving.

  6. 6

    Say Hello Chat

    Talk to Codex as usual, then say Bye Chat.

For Spotify volume, separate the value with “percent”: “Spotify volume forty percent three times”. For music, each run is another Play/Pause press, so an even number can leave playback as it was. Each command has its own short sound. Wake and End acknowledge detection; audio and video cues follow the confirmed result. Music, app and zoom cues acknowledge dispatch. Check the app’s status for the outcome.

Speech During Voice Startup

H Chat keeps the opening words it hears while a new Voice call connects in a private local file. App startup installs its own Codex skill to read that file once. It preserves user-edited or conflicting skills.

The new local Voice coordinator needs a work turn to read the file. Installing the skill does not make the conversational model wait for it before replying. H Chat does not paste into the composer or switch chats. Read the capture and recovery details.

Privacy

Wake and end detection run on your Mac with no account, API key or server; the conversation itself happens in Codex.

On Your Mac

  • Listens to the microphone you choose, only while listening is on.
  • Recognises speech locally, by default with the bundled Nemotron model through Core ML on CPU and Neural Engine, with GPU off.
  • Doesn’t save audio.
  • Saves transcripts of what it heard as JSON with rough phrase timestamps. This is on by default; turn off Save transcripts in Settings → Transcript Archive to stop.
  • Keeps listening while Voice or Agent Flow is recording, so wake and end phrases still work. Transcripts can include your side of the conversation and background speech.
  • Keeps transcripts on your Mac unless you set up the optional Google Drive backup.
  • Writes timing and error logs that exclude recognised words.
  • Optional notification replies use the same microphone and local model. The app checks the exact originating chat for newer input, then sends the completed reply only to that chat. The shared notification-speech integration is required; no second recognizer or audio recording is added. Setup and controls.
  • Each command has a short sound. Settings → Sounds controls their volume without changing your system volume or speakers.
  • Sound effects, optional Spotify control and paired-Mac priority observe Codex’s native call controls and read saved call-start/end metadata. This enables the End sound when you close Voice directly in Codex. No conversation text is read. Turn all three features off to stop background call monitoring.
  • Optional Spotify control lowers its own volume during chat and restores it afterward, unless changed manually. It reads call controls and saved call-boundary metadata, never tracks or transcripts. This is off by default and needs macOS Automation permission.
  • Never downloads models while listening. The Core ML models are bundled and pinned by SHA-256.

In Codex

  • H Chat fills missing Voice shortcuts in Codex’s local keybindings file and installs its app-owned startup skill. Custom shortcuts and user-edited skills are preserved. Speech captured during startup uses a separate private pending file even if transcript archiving is off.
  • Runs the Voice conversation, including its audio and network connection.
  • Uses your Codex sign-in and its own microphone setting.
  • Needs internet, and Voice available on your account.
Siri and Vocal Shortcuts

Apple’s Shortcuts app includes eight Hello Chat actions: start, end, microphone mute and unmute, speaker silence and restore, Set Voice to Ultrafast, and read-only chat status. They use the same native Codex controls. Starting through a shortcut does not turn local listening on.

Set Voice to Ultrafast is also in Settings and the menu bar. It selects Ultrafast for the current local Voice chat’s next turn, keeping its model, reasoning and draft. It needs one unambiguous chat pane and does not change new-chat defaults.

On a supported Mac, Accessibility → Vocal Shortcuts can connect a phrase trained with your own voice to an action or saved shortcut. Apple processes that recognition on the device. Setup is optional and does not switch off Hello Chat’s existing detector. Compare them separately before enabling a replacement.

Fixed phrases do not replace variable app names, continuous transcripts or startup speech capture. Accuracy and power use versus Nemotron are unmeasured. Apple’s setup guide

Speech Models

Choose one with Speech model in the main window. All four run on your Mac. The three Core ML models are bundled, so the app is about 1.09 GB.

Nemotron · 560 ms
The default: NVIDIA’s larger Nemotron Speech Streaming 0.6B model, run locally through Core ML and FluidAudio 0.17.7.
Parakeet EOU · 320 ms
NVIDIA’s Parakeet Realtime EOU 120M, converted to Core ML by Fluid Inference.
Parakeet EOU · 160 ms
Lower latency. It missed more words in earlier recorded checks.
Apple Speech · local
macOS 26 only, using English speech assets already installed on your Mac. Apple doesn’t expose where it runs, so Neural Engine use is unverified. If the assets are missing, Hello Chat shows an error instead of downloading them.

The Core ML models need a Neural Engine. Before listening, Hello Chat checks that Core ML’s compute plan puts most of the encoder there. That’s an estimate, not measured use, and the CPU still does part of the work.

Build From Source

Download the signed, notarised app, or build it on your Mac.

Requirements

  • A Mac with Apple Silicon, on macOS 15 or later
  • Xcode 26 or later, for Swift 6.2
  • Python 3
  • Internet for the first build, which downloads the pinned speech models from Hugging Face
Terminal 
git clone https://github.com/EthanSK/hello-chat.git
cd hello-chat
zsh scripts/build.sh
zsh scripts/test.sh
open .build.noindex

The build verifies every model file’s SHA-256, then signs .build.noindex/HelloChat.app. The tests never use your microphone or start Voice. Copy HelloChat.app from the opened build folder to Applications, then open it. Normal builds update through Check for Updates in the app menu or Settings. When replacing a source build manually, quit Hello Chat and move the old copy to the Bin before copying the new one.

Signing and Build Options

The build signs with your first Developer ID Application certificate, or ad-hoc when there isn’t one. Set HELLOCHAT_SIGNING_IDENTITY to pick another identity. macOS ties Microphone and Accessibility permission to the signature, so with ad-hoc signing it may ask again after a rebuild.

Source builds use the public updater by default. An update from an ad-hoc signature to the public Developer ID may need fresh microphone or Accessibility permission. Remove the production public key only if you want a separate development build without updates.

Set HELLOCHAT_BUILD_DIR to an absolute path to put all build output, models and test executables somewhere else.

Start at Login

Quit Hello Chat, then run python3 scripts/install-startup.py. It adds a LaunchAgent that opens /Applications/HelloChat.app at login and reopens it after a crash. Quit still quits.

Google Drive Backup

Optional and separate from the app. scripts/install-transcript-backup.py installs a daily LaunchAgent that copies one JSON snapshot per changed day to Google Drive while your Mac is on power. It needs rclone with your own Google Drive remote, and never uploads audio or deletes remote files.

python3 scripts/install-transcript-backup.py --install \
  --rclone-config /path/to/rclone.conf \
  --destination 'remote:HelloChat Backup/Transcripts'

Run it without --install to print the LaunchAgent first.

Recorded Checks

.build.noindex/HelloChat.app/Contents/MacOS/HelloChat --check-speech runs the bundled test recordings through the real model and matcher. Add --model parakeet160, nemotron560 or appleLocal to try another model. Settings → Recognition → Check speech recognition does the same from the app.

These use fixed recordings, so they don’t show how well it hears you in your room.

Help

Check what H Chat heard and the status shown on Home before changing your setup.

Voice Does Not Open

After your current call ends, test the configured Voice chat hotkey in the same Codex or ChatGPT presentation. If it also fails manually, check native Voice availability and shortcut registration. H Chat cannot enable Voice for your account.

H Chat preserves existing shortcuts. Newly saved bindings may need a Codex restart; Home shows that notice. Keep Start, End and Toggle voice chat separate. Shortcut and presentation details.

No Words Are Heard

Check Home’s listening status, microphone choice and level bar. System default follows your Mac’s input; Codex Voice has its own microphone setting. Automatic listening is optional and waits 2 minutes after power and an external display connect. You can turn listening on yourself immediately.

Check Microphone and Accessibility in System Settings → Privacy & Security. Settings → Recognition → Check speech recognition uses bundled recordings, so it checks the local pipeline without starting Voice. It does not test your microphone or room.

Updates and Optional Setup

Release builds have Check for Updates in the app menu and Settings, with automatic checking and downloads. Update installation waits for H Chat’s own work, then restarts the helper without ending an independent Codex call or Agent Flow recording.

Start at Login and Google Drive backup are optional scripts in the source repository; they are not installed automatically with the download. Paired-Mac Voice priority also needs manual setup and Agent Bridge. Pairing instructions.

Report an issue with your app version, macOS version, selected model and the error shown. Keep private transcripts out of public reports.

Limits

  • It isn’t speaker-locked: anyone the microphone can hear, including a video, can wake or end Voice.
  • Matching leans towards waking, so it can hear a phrase nobody said, or miss one.
  • It works through Codex’s Voice shortcut and End Voice control, not an official wake-word API. A Codex update can change them, and Hello Chat then shows an error instead of guessing.
  • H Chat fills missing Start and End shortcuts with Command-Control-Shift-V and Control-Option-Shift-V. Custom shortcuts are preserved, including character, function and navigation keys. If Codex was already running when a binding was added, restart Codex once to apply it. Toggle voice chat is a separate command.
  • Listening always uses some CPU, because Core ML shares the work between CPU and Neural Engine. Settings → Resources shows Hello Chat’s own CPU and memory.
  • Detection is local, but it isn’t an offline assistant: Codex Voice needs internet.
  • So far it’s been used on Ethan’s own Mac, not tested across a range of fresh setups.
