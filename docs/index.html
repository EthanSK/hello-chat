Setup

Check Codex Voice works on its own first, then let HelloChat open and end it.

  1. 1

    Start Voice in Codex yourself

    Sign in to the Codex desktop app and check Voice works. HelloChat can only open Voice that Codex already offers you.

  2. 2

    Build HelloChat

    Build from source, then copy HelloChat.app to Applications.

  3. 3

    Allow Microphone and Accessibility

    Microphone is for local listening. Accessibility lets HelloChat use Codex’s Voice shortcut and End Voice control.

  4. 4

    Choose your microphone

    Settings → Microphone. Codex Voice keeps its own input setting.

  5. 5

    Turn on Listen for wake phrase

    HelloChat prepares the local model, then shows Listening.

  6. 6

    Say Hello Chat

    Talk to Codex as usual, then say Bye Chat. Voice also ends after 1 minute of silence by default.

Phrases

These are the defaults, and you can change both in Settings → Phrases.

Hello Chat

  • Opens Voice in Codex. No need to turn it on first.
  • Works after other speech, such as “I stopped the video, Hello Chat”.
  • Ignores clear mentions, such as “I said Hello Chat”.
  • Also matches close mishearings such as Harlow Chat while Allow small spelling differences is on, which it is by default.
  • Plays the Wake sound when Voice opens.

Bye Chat

  • Ends Voice in Codex, after checking Codex’s End Voice control is showing.
  • Cancels Voice while it’s still opening.
  • Ends a Voice call you started yourself in Codex too.
  • Plays the End sound straight away.
  • If Voice is already off, HelloChat says so and does nothing else.

Voice also ends after 1 minute of silence. Change it to 30 seconds or 2 minutes with End Voice after silence in Settings → Phrases.

Privacy

Wake and end detection run on your Mac with no account, API key or server; the conversation itself happens in Codex.

On Your Mac

  • Listens to the microphone you choose, only while listening is on.
  • Recognises speech locally, by default with a bundled Parakeet model through Core ML on CPU and Neural Engine, with GPU off.
  • Doesn’t save audio.
  • Saves transcripts of what it heard as JSON with rough phrase timestamps. This is on by default; turn off Save transcripts in Settings → Transcript Archive to stop.
  • Keeps listening while Voice is on, so it can hear Bye Chat. Transcripts can include your side of the conversation and background speech.
  • Keeps transcripts on your Mac unless you set up the optional Google Drive backup.
  • Writes timing and error logs that exclude recognised words.
  • Never downloads models while listening. The Core ML models are bundled and pinned by SHA-256.

In Codex

  • Runs the Voice conversation, including its audio and network connection.
  • Uses your Codex sign-in and its own microphone setting.
  • Needs internet, and Voice available on your account.
Speech Models

Choose one with Speech model in the main window. All four run on your Mac. The three Core ML models are bundled, so the app is about 1.09 GB.

Parakeet EOU · 320 ms
The default: NVIDIA’s Parakeet Realtime EOU 120M, converted to Core ML by Fluid Inference and run through FluidAudio 0.17.7.
Parakeet EOU · 160 ms
Lower latency. It missed more words in earlier recorded checks.
Nemotron · 560 ms
NVIDIA’s larger Nemotron Speech Streaming 0.6B model.
Apple Speech · local
macOS 26 only, using English speech assets already installed on your Mac. Apple doesn’t expose where it runs, so Neural Engine use is unverified. If the assets are missing, HelloChat shows an error instead of downloading them.

The Core ML models need a Neural Engine. Before listening, HelloChat checks that Core ML’s compute plan puts most of the encoder there. That’s an estimate, not measured use, and the CPU still does part of the work.

Build From Source

There’s no signed, notarised download yet, so build it on your Mac.

Requirements

  • A Mac with Apple Silicon, on macOS 15 or later
  • Xcode 26 or later, for Swift 6.2
  • Python 3
  • Internet for the first build, which downloads the pinned speech models from Hugging Face
Terminal 
git clone https://github.com/EthanSK/hello-chat.git
cd hello-chat
zsh scripts/build.sh
zsh scripts/test.sh
ditto .build.noindex/HelloChat.app /Applications/HelloChat.app
open /Applications/HelloChat.app

The build verifies every model file’s SHA-256, then signs .build.noindex/HelloChat.app. The tests never use your microphone or start Voice. To update, quit HelloChat and move the old copy to the Bin before copying the new one.

Signing and Build Options

The build signs with your first Developer ID Application certificate, or ad-hoc when there isn’t one. Set HELLOCHAT_SIGNING_IDENTITY to pick another identity. macOS ties Microphone and Accessibility permission to the signature, so with ad-hoc signing it may ask again after a rebuild.

Set HELLOCHAT_BUILD_DIR to an absolute path to put all build output, models and test executables somewhere else.

Start at Login

Quit HelloChat, then run python3 scripts/install-startup.py. It adds a LaunchAgent that opens /Applications/HelloChat.app at login and reopens it after a crash. Quit still quits.

Google Drive Backup

Optional and separate from the app. scripts/install-transcript-backup.py installs a daily LaunchAgent that copies one JSON snapshot per changed day to Google Drive while your Mac is on power. It needs rclone with your own Google Drive remote, and never uploads audio or deletes remote files.

python3 scripts/install-transcript-backup.py --install \
  --rclone-config /path/to/rclone.conf \
  --destination 'remote:HelloChat Backup/Transcripts'

Run it without --install to print the LaunchAgent first.

Recorded Checks

.build.noindex/HelloChat.app/Contents/MacOS/HelloChat --check-speech runs the bundled test recordings through the real model and matcher. Add --model parakeet160, nemotron560 or appleLocal to try another model. Settings → Phrases → Check speech recognition does the same from the app.

These use fixed recordings, so they don’t show how well it hears you in your room.

Limits

  • It isn’t speaker-locked: anyone the microphone can hear, including a video, can wake or end Voice.
  • Matching leans towards waking, so it can hear a phrase nobody said, or miss one.
  • It works through Codex’s Voice shortcut and End Voice control, not an official wake-word API. A Codex update can change them, and HelloChat then shows an error instead of guessing.
  • Codex’s Voice shortcut is Control-Shift-V by default. A custom one needs to end in V, F16, F17, F19 or F20.
  • Listening always uses some CPU, because Core ML shares the work between CPU and Neural Engine. Settings → Resources shows HelloChat’s own CPU and memory.
  • Detection is local, but it isn’t an offline assistant: Codex Voice needs internet.
  • Listening pauses while a Bose Flex 2 SoundLink is the selected playback output. That’s a rule for Ethan’s own speaker.
  • So far it’s been used on Ethan’s own Mac, not tested across a range of fresh setups.
